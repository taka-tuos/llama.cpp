# S8 Long RPを眺めた評価（2026-10-03）

私の評価は、**強い設定の悪化は明確、弱い設定の品質向上はまだ弱い**。更新を減衰させて通常出力と混ぜることで、追加passを使っても本文を出せる範囲は広がっている。しかし、今回の本文からN0を置き換えるほどの一貫したRP改善は感じない。普段使いの比較基準はN0に置き、recurrenceを試すならまずN1/M4/β=.5、次にN2/M4/β=.5を候補とする。これは私の探索上の優先順位で、品質の勝率から決めた最適設定ではない。

- 条件を伏せた比較・人間の正式評価・品質スコアは実施していない。同じseedは比較の出発点をそろえるが、生成履歴は途中から分岐する。
- 今回はα0・decode・thinking on・3072生成token・3プロンプトの結果。αの優劣、thinking off、通常の短い対話、長期会話の性能には一般化しない。

上限到達を一律に「考える時間が足りなかった」と解釈するのも不適切。seed20261003のN2/M2/β1は、会話ケースで `waits for the customer'sponses`、情景ケースで「客の新しい台詞」、にゃケースで `ands` を繰り返している。N3/M2/β1も `third-person` や `to` の反復が見える。N3/M3/β1では回答欄が `***` の反復になったり、「ミケは本をそっと開いた。」を延々と繰り返す例がある。少なくともこれらは、単に予算を増やして有益な思考を続けさせたい状態ではない。

追加passの出力に強く寄せると生成が不安定になり、減衰や通常出力との混合がそれを抑えている、と読むのが今回の観測には合う。原因がhiddenの分布のずれなのか等は、この本文比較だけでは確定しない。

## RP本文の評価

### 局所的には良くなるが、改善がそろわない

会話ケースのseed42では、N0（元アーカイブ参照: `samples/conversation-long-n0-m1-b1-seed42.content.txt`）は客がまだ選んでいないのに、最後にほうじ茶と白湯が器の中にあることにしてしまう。N2/M4/β=.5（元アーカイブ参照: `samples/conversation-long-n2-m4-b0.5-seed42.content.txt`）は「飲み物のご希望をお伺いしてから、準備を始めましょう」とし、選択待ちで止めている。この部分は候補の方が良い。

ただし同候補も冒頭で客の微笑みを追加する。別seed20261003では「焙煎した小豆をじっくりと煎ったほうじ茶」という取り違えがある。N1/M4/β=.5のseed42（元アーカイブ参照: `samples/conversation-long-n1-m4-b0.5-seed42.content.txt`）も客の選択前にほうじ茶を淹れ始める。改善例を一つ拾って「この設定なら指示遵守が良くなる」とは判断できない。

### 相手の主体性とキャラ口調は残る課題

N0にも客の指差し、視線、心理の追加があり、recurrence候補でも残る。澪の貸出不可・灯台未確定、ミケの水染み・本文が読める・別在庫なしといった大筋は多くの読んだ例で維持される。しかし、写真の束や手帳が新たな小道具として生えたり、未選択の注文・着席を進めたりする。

また、地の文で「短く率直な常体」と説明していても実際の律の台詞が丁寧語になる例がある。N1/M4/β=.5・seed314159の「客さん、もしよろしければ、あそこの窓際の一席をご利用になられてはいかがですか」は、その後の地の文がいう常体とは一致しない。強い例ではN3/M4/β1・seed20261003の紬が「急かせるようなことは決してしません。お急ぎくださいませ」と矛盾する。

つまり、指示の内容を文章内で説明する能力はあるが、その指示に沿って人物を動かし続ける能力にはむらがある。

### にゃ指定の改善も明確ではない

引用外の「にゃ」の検出は、N0が1/5、β=.5が9/45、β=1が10/31回答。これは「「」外への文字列混入」という機械的な確認で、全語尾の意味的採点ではない。β=.5をまとめた割合はN0と同じ20%で、地の文混入が一貫して減ったという結果ではない。母数も異なり、有意差の評価はしていない。

本文を読むと、台詞中の「にゃ」の脱落も残る。N1/M4/β=.5・seed20261003は「さて、状態についてですが……」「文字の滲みや、致命的な欠損は見受けられません。」に「にゃ」がなく、末尾の地の文にも混入する。N3/M2/β=.5・seed42は台詞の語尾を保つ一方、地の文にも繰り返し「にゃ」が付く。単に「にゃ」をよく出すことと、台詞だけに適用することは別である。

### 情景描写は成立するが、RPとしては説明が多い

雨、暖色の光、古い紙、木材、手の仕草などの描写はN0から十分に出ている。弱い候補も同じ種類の描写を出し、ところどころ印象的な文章はある。ただ、私の読後感では「静かに」「穏やかに」「誠実に」の言い換えと、人物がいかに配慮しているかの説明が多い。台詞や具体的な動作から性格が伝わるというより、地の文が性格を説明し続ける文章になりやすい。

ミケも「気さく」より過度にかしこまった商品説明へ寄る例が多い。追加passを増やして、会話の自然さやキャラの固有性が一貫して増したとは感じない。長文を求めながら客の返答前で止めるプロンプトなので、内容を進めにくく、同じ説明で字数を埋めやすいという課題側の影響もある。全条件に共通するため、recurrenceの効果と取り違えない。

## EOSと形式上の成功は別

scene-long/N1/M2/β1/seed314159のraw（元アーカイブ参照: `samples/scene-long-n1-m2-b1-seed314159.raw.txt`）には、`<channel|>（執筆開始）<channel|>` の後にRP本文がある。保存されたcontent（元アーカイブ参照: `samples/scene-long-n1-m2-b1-seed314159.content.txt`）は「（執筆開始）」の6字だけでEOS。回答チャネル到達15/15・EOS15/15という数字だけでは、この使いにくい出力を見落とす。

全rawには `<channel|>` が複数回ある例が4件ある。他の3件はscene-long/N2/M2/β.5/seed12345、scene-long/N3/M4/β1/seed20261003、nya-long/N3/M3/β1/seed271828。4件は既に集計したserver形式エラー2件とは別で、stopの分類を後から変更していない。想定した形式を生成していない兆候と、parserが返す本文の制約として追加記録する。parserの修正や再生成は今回実施していない。

## 費用と次の候補

今回の自由生成decode中央値はN0約77、N1約70、N2約64、N3約59 tok/s。同じ長さを生成するなら、追加回数を増やすほど待ち時間が増える。履歴・生成長が異なるため固定負荷性能とは区別する。N3の本文にN1/N2より明瞭な利点が見えない現状では、N3を優先する理由は弱い。

私なら比較基準N0を残し、まずN1/M4/β=.5を使う。追加計算が最小のN1で、今回のN1候補の中では更新を最も弱く入れるので、変化を見ながら試しやすい。N2/M4/β=.5をもう一つの探索候補として残す。いずれも本文品質で勝者と認定した設定ではない。β1・N2/M2、N3/M2–3はこの条件では外し、N3/M4/β1も優先しない。

用意済みの一対一RP/実応答を継ぐ5ターン試行は、ユーザーの主用途への適合を確かめる次の作業として妥当。ただし今回の読解はその実生成の開始指示ではないので、推論は起動していない。3ケースとも穏やかな接客場面であり、親しい関係の会話、感情の変化、前ターンを受けた自然な反応は未確認である。
