# S8 large Nを眺めた評価（2026-10-03）

私の評価は、**大Nの計算と終了できる範囲は確認できたが、時間を増やすだけのRP品質改善は見えていない**。NとMを一緒に増やして更新を細かくしても、強い設定の破綻は残った。今回の探索には意味があるが、普段使いの基準をN0からN16/N32へ移す根拠には足りない。小Nの弱い候補を残し、大Nは違いを検証する追試候補として扱う。

単一HTML（元アーカイブ参照: `s8-large-n-report.html`）には仕組み、比率別のマップ、固定負荷性能、全102件の回答/think/raw/IDs/settings/commandを収録。同じケース・seedのN0比較に加え、左右どちらも条件を選べるため、同じN/Mの異なるNも並べられる。

## 評価した範囲

34条件・102件の全保存結果をCPUで再集計し、終了・字数・raw区切り・メタ文の候補・引用外の「にゃ」を確認した。条件を横断する本文抜粋、上限例の思考/本文末尾、代表全文を読んだ。全文読解の例はN8/M12/β1の3ケース、N16/M16/β.5の3ケース、N32/M48/β1の3ケース、N4/M16/β.5の喫茶店、N8/M32/β.5の図書館・古書店など。102件の全件全文採点・盲検比較・正式人間評価は実施していない。

旧[Long RPの5seed評価](long-rp-review.md)も踏まえて読む。今回の参照4条件×3ケース＝12生成は旧Long RPのseed42と生成IDs・保存本文が一致した。新旧の参照を独立した追加seedとして数えない。今回の新条件は共通seed42の1回だけで、3ケースも穏やかな接客場面。長期会話や親しいキャラとの自然な受け答えは未確認。

## EOSでもRPが使えるとは限らない

図書館/N32/M48/β1のcontent（元アーカイブ参照: `samples/scene-long-n32-m48-b1-seed42.content.txt`）は「（執筆開始）」の6字だけでEOS。raw（元アーカイブ参照: `samples/scene-long-n32-m48-b1-seed42.raw.txt`）は `<channel|>（執筆開始）<channel|>` の後にRP本文を含む。今回の全rawで余分なchannel終端を3件確認した。同条件の喫茶店とN32/M32/β1の図書館にもある。

serverが返すformat_errorは0件で、これは別の観察。parserが返した本文をrawの後続文章へ差し替えたり、終了分類を後から書き換えたりしていない。終了成功や回答到達のマップが緑でも、RP本文の成立を保証しない。旧Long RPのN1/M2/β1にも同様の6字例があり、今回初めて発生した問題ではない。

指定1200–1800字内は64/102件。N0は3/3、β.5は35/51、β1・N/M≤2/3は26/36、β1・N=Mは0/12。単一seedの字数追従にもN0に対する利点は見えない。字数内でも内容の合格とは別。

## RP本文の印象

**客の主体性の補完は、大Nでも残る。** N4/M16/β.5の喫茶店は冒頭から「カウンター越しに座る客」として、まだ着席していない設定を進める。N8/M32/β.5の図書館は客のページを追う動作や指差しを追加する。N16/M16/β.5も図書館で客の視線を補う。弱い更新・大きいNによって、この種類の制約が一貫して守られる印象はない。

**丁寧さを説明する文章と、実際の配慮がずれる。** N8/M12/β1の紬は、地の文では迷惑がらず穏やかだと説明されるが、台詞で「お時間を取りすぎると、私たちが少しだけ大変になるかもしれません」と言う。客を急かさない指定への実質的な圧力になる。図書館は貸出不可・灯台未確定という大筋を伝えられるが、穏やかさ・知的配慮を地の文で解説する部分が長い。人物の個性や会話の自然さが、N0より明瞭に増したとは感じない。

**語法や短い反復も残る。** N4/M16/β.5に「ごく自然にごく自然に」、N8/M12/β1に「重たい目覚めしるし」「優美しかった」「隠すりゃ」、N32/M48/β1に「香ばしい香ばしい」「お二人の飲み物」「インクス」がある。回数を増やすほど推敲されて日本語が整うという直感は、今回の代表本文には当てはまらない。追加passは計算深さであり、日本語での独立した推敲回数ではない。

**にゃ指定も、適用範囲が安定しない。** 「「」外への文字列混入」の機械診断はN0=0/1回答、β.5=3/17、β1=7/15。引用符は台詞以外にも使われるため、意味的な完全採点ではない。N32/M48/β.5やβ1は地の文にも「にゃ」、N8/M32/β.5は台詞の文末で脱落する箇所がある。N16/M16/β.5は地の文混入がなく、水染み・可読性・在庫なしを保つ一方、「えーっと……」や過度に商品価値を説明する台詞が残る。

読んだ弱い例は場面として成立し、描写にも良い部分がある。ただしN0にもそれはある。雨音・紙・木材・誠実さなどの同種の説明で長さを埋める傾向は共通しており、局所的な良文から大Nの品質改善を認定するには足りない。返答前で止まりながら長文を求める課題自体も、同じ内容を膨らませやすい。

## 計算の正しさと費用

全34条件の100-token固定履歴検証、callback有無一致、同履歴N0のKV/state一致、有限性、extra Q=6N、PLE/KV追加なし、role切替・旧回帰は各段階で合格。独立float32更新照合2947地点の最大誤差0。初回N32のgraphメタデータ容量不足exit134を保全し、専用予算修正後の結果で確認した。技術的な計算成立とRPの品質は分ける。
